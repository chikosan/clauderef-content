## Who's behind this

I'm Shai Chikorel, a DevOps engineer who spends most of the day building,
automating, and operating systems. Claude Code became one of the tools I reach
for constantly, and ClaudeREF.com grew from the notes I kept while learning how
to use it well.

## Why ClaudeREF.com exists

Claude Code moves fast. Flags change, slash commands get added, skills and
subagents evolve, MCP wiring gets easier every release — and the useful details
end up scattered across changelogs, threads and videos.

ClaudeREF turns those scattered details into one practical, fast place for all
of it:

- A complete, searchable command reference you can read in one screen.
- News on Claude and Claude Code, dated and short.
- Articles and video write-ups worth your time, with TL;DR takeaways.
- Everything readable from the terminal — `curl https://clauderef.com/cheatsheet`.

No signup, no tracking wall, no fluff. Just the reference I wanted to exist,
kept useful for anyone learning or working with Claude Code.

## How it's built

The knowledge base lives as public Markdown and structured data in the
[ClaudeREF content repository](https://github.com/chikosan/clauderef-content).
Every page is a reviewable file, while the website application and deployment
remain private. The terminal endpoints return ANSI, JSON, Markdown or plain
text from the same reviewed content snapshot.

## Contribute or say hi

Found a wrong flag, a missing command, a useful repository, or a workflow worth
sharing? Visit the [contribution page](https://clauderef.com/contribute), send it
to [hello@clauderef.com](mailto:hello@clauderef.com), open a GitHub issue, or
contribute a pull request. Small corrections and practical examples are
especially welcome.
