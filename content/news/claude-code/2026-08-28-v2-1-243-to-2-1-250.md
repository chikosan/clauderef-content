Claude Code moved from **v2.1.241 to v2.1.250** between August 25 and August 28, 2026. The most useful changes are aimed at safer evaluation environments, tighter model and cache control, more capable multi-session workflows, and better reliability for long-running sessions.

## Changes worth noticing

- **Restricted execution mode:** v2.1.248 adds `--restricted` (or `CLAUDE_CODE_RESTRICTED=1`) for evaluation and shared-machine scenarios. It removes command/code execution tools and `WebFetch` unless explicitly named, confines built-in file tools to working directories, ignores user/project/local settings, and refuses `bypassPermissions`.
- **Model and cache controls:** v2.1.243 adds `modelPicker` so organizations and users can curate the model picker. The same release adds `promptCacheTtl` and `subagentPromptCacheTtl` for API-key and cloud-provider users, plus managed `modelPricing` for organization-specific cost reporting.
- **Cross-session and enterprise workflows:** v2.1.248 expands `SendMessage` / `ListAgents` cross-session messaging to Bedrock, Vertex, Foundry, and telemetry-disabled sessions, and adds better diagnostics when server-managed settings fail to load.
- **Feedback and API workflows:** v2.1.247 adds the `SendFeedback` tool so Claude can draft feedback for review, plus `/claude-api cost-optimize` and broader Admin API reference coverage in the bundled Claude API skill.
- **Permission and reliability fixes:** v2.1.246 adds an Auto mode tab under `/permissions`, warns about risky Bash allow-rule wildcard placement, and fixes several background-session, MCP, sandbox, and long-session failure modes. v2.1.250 is a bug-fix and reliability release.
- **Prompt-cache stability:** v2.1.248 fixes an hourly prompt-cache miss that could also lose extended-thinking context after OAuth token refresh, which matters most in long interactive sessions.

## What to do

Update Claude Code, then review any CI/evaluation harnesses that can benefit from restricted mode and any managed model-policy configuration:

```bash
claude update
claude --restricted -p "inspect this repository and summarize its architecture"
```

If you maintain shared settings, verify `modelPicker` precedence before rolling it out broadly. Treat the new cache TTL and pricing controls as release-note features until the corresponding reference pages document the exact schema you intend to deploy.
