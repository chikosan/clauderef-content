Claude Code **2.1.216** is out. Highlights:

- Added `sandbox.filesystem.disabled` — skip filesystem isolation while keeping network egress control.
- Fixed message normalization slowdown in long sessions (quadratic token cost).
- Fixed auto mode denying commands after OAuth token expiration.

```bash
claude update
```
