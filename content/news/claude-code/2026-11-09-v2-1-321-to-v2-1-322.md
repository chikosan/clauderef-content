Claude Code **v2.1.321** and **v2.1.322** are a compact but meaningful pair of releases. The first combines a new default Fable model and a practical Remote Control configuration switch with security and permission fixes. The second adds fast mode on Vertex in three regions. Together, they matter most to teams running long-lived remote sessions, using MCP sign-in, or routing Claude Code through Google’s hosted model platform.

## Remote Control can carry a settings file

Version 2.1.321 adds `--settings <file>` to `claude remote-control`. The file is applied to every session that Remote Control starts. If the file changes while the server is running, Claude Code does not start a new session with the changed values until `claude remote-control` is restarted. That restart boundary is important: treat the file as part of the Remote Control process configuration, not as a live per-session editor.

This gives operators a cleaner way to keep remote sessions aligned with a known model, permission policy, environment, or other supported setting. It also creates a new review point for launch scripts: confirm the settings file is readable, intentionally scoped, and does not contain credentials before exposing the session to another device. The official settings documentation describes `--settings` as a per-session source above user, project, and local files, while managed settings remain higher priority.

## Fable 5.2 becomes the default Fable model

The same release adds Claude Fable 5.2 under `claude-fable-5-2` and makes it the default Fable model. Anthropic’s release notes list a 1M-token context window, $8 per million input tokens, $40 per million output tokens, and $0.20 per million cache reads. Those figures are useful for planning, but availability and billing still depend on the account and provider surface. Do not assume that changing the local model picker changes an organization’s model policy.

Saved Fable 5.1 selections move to `fable` on Pro and Max immediately, and on Team and Enterprise once the organization allows it. Users who need the earlier model can select `claude-fable-5-1` explicitly, subject to availability. A canary session is a sensible place to check prompts, cost, tool behavior, and context handling before changing a shared workflow.

## An MCP OAuth redirect fix closes a risky edge case

One v2.1.321 fix addresses MCP OAuth requests that could send secrets such as refresh tokens to another host after a server redirect. That is a security-relevant change for anyone using authenticated remote MCP servers: upgrade, then re-authenticate only with servers you trust and review the redirect and callback configuration on the server side. The release also tightens several permission and sandbox paths, including read-only Bash execution, writes judged from the wrong folder, and `cp` or `mv` operations that bypassed deny-rule or protected-file checks.

The broader lesson is to treat MCP authentication and filesystem permissions as separate controls. A successful OAuth login does not make a server safe, and a correct deny rule still needs a client version that applies it to the actual operation. Keep the CLI updated in environments where MCP servers can access sensitive systems.

## Vertex fast mode is regional

Version 2.1.322 adds fast mode on Vertex in the global, US, and EU regions. If Vertex refuses fast serving, Claude Code falls back to standard speed. This is an availability improvement, not a promise that every request becomes faster: capacity, model support, account configuration, and region still matter. Test the same region and provider settings used in production, and watch for the fallback rather than assuming that a fast-mode label guarantees fast serving.

## What to do

Upgrade a small canary first. For Remote Control, pass the intended settings file explicitly and restart after edits. For MCP, verify the server’s OAuth redirect behavior and re-test a protected filesystem operation. For Vertex, test fast mode in the region that serves your users and record whether requests remain fast or fall back to standard speed.

```bash
claude update
claude --version
claude remote-control --settings ./settings.json
```
