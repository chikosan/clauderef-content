Anthropic increased capacity for heavy Claude and Claude Code users on May 6.

## What changed

- Five-hour Claude Code rate limits doubled for Pro, Max, Team, and seat-based Enterprise plans.
- Peak-hour limit reductions were removed for Pro and Max accounts.
- Claude Opus API rate limits increased across published usage tiers.

## Why it matters

The change gives paid users more continuous Claude Code time without changing the basic limit model. Usage is still governed by rolling windows, plan rules, model choice, and workload intensity.
