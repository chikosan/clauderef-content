Anthropic released **Claude Opus 4.6** as an upgrade for difficult coding and agentic work.

## What changed

- Better planning, code review, debugging, and reliability across larger codebases.
- Longer sustained agentic work with more careful self-checking.
- A beta 1M-token context window for Opus-class workloads.
- Improvements across research, finance, documents, spreadsheets, and presentations.

## Why it matters

The larger context window makes more repository and document material available in one request, but it does not remove the need to keep instructions focused. Longer agent runs also deserve explicit tests and budget limits.
