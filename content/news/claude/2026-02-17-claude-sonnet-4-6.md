Anthropic released **Claude Sonnet 4.6** as a broad upgrade across coding, computer use, planning, knowledge work, and visual design.

## What changed

- Sonnet 4.6 became the default model on Claude Free and Pro plans.
- API pricing stayed at the previous Sonnet level, starting at $3 per million input tokens and $15 per million output tokens.
- A beta 1M-token context window expanded the amount of code and reference material one request can contain.
- Anthropic reported better instruction following, less overengineering, and more reliable multi-step follow-through in Claude Code testing.

## Why it matters

Many tasks that previously pushed users toward an Opus model became practical at the Sonnet tier. Computer-use workflows still need prompt-injection defenses and human review of consequential actions.
