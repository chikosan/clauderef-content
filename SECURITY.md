# Security policy

## Supported version

Security fixes target the current `main` branch and current production deployment. Older commits and
forks are not maintained releases.

## Reporting a vulnerability

Please report suspected vulnerabilities privately by emailing
[hello@clauderef.com](mailto:hello@clauderef.com). Do not open a public issue before a fix or safe
disclosure has been coordinated.

Include, when possible:

- the affected URL, component, or commit;
- impact and realistic attack conditions;
- minimal reproduction steps; and
- suggested remediation or disclosure constraints.

Do not send credentials, private user data, or destructive proof-of-concept payloads. You should
receive an acknowledgement when the report is reviewed; timing for investigation and remediation
depends on severity and reproducibility.

Good-faith research that avoids privacy violations, service disruption, social engineering, data
destruction, and access beyond what is needed to demonstrate the issue is welcome. Please allow a
reasonable remediation period before public disclosure.
